## Usage

Default variant — horizontal on desktop, vertical on mobile:

```tsx
import { StepsSection } from "@olwiba/ui";

<StepsSection
  title="From zero to shipped"
  steps={[
    { emoji: "✍️", title: "Sign up", description: "Create an account in seconds." },
    { emoji: "🚀", title: "Ship", description: "Go live with confidence." },
  ]}
/>
```

Timeline variant — numbered circles on a vertical accent line whose ends fade out. Groups chain with interstitial content (the line fades out after a group and fades back in before the next), and numbering continues across groups:

```tsx
<StepsSection
  variant="timeline"
  title="Up and running in minutes"
  groups={[
    {
      steps: [
        { title: "Create your account", description: "Sign up with your email." },
        { title: "Add your first monitor", description: <>Send <code>!bot start</code> to activate.</> },
      ],
      after: <CtaCard />,
    },
    {
      steps: [{ title: "Found what you needed?", description: "Cancel anytime." }],
    },
  ]}
/>
```

Step descriptions are `ReactNode` — code chips, forms, and demo cards all work inline.

### Connected steps

Use centered emoji, titles and descriptions on an open section. Each step has
a soft elliptical accent glow. A single scroll-triggered sequence draws each
dashed accent connector to the next emoji before that emoji, copy and glow
arrive. There are no tile borders or grey idle tracks. Desktop connectors join
the emoji wrappers; reduced-motion and data-saver users see the complete sequence
immediately. Steps form a row on desktop and stack with
vertical connectors below the large breakpoint. Content remains visible before
hydration and without JavaScript.

```tsx
<StepsSection
  variant="connected"
  surface="plain"
  title="From idea to launch"
  steps={[
    { title: "Generate", description: "Choose the modules your product needs." },
    { title: "Build", description: "Make the product yours." },
    { title: "Ship", description: "Deploy and share it with your first customers." },
  ]}
/>
```
