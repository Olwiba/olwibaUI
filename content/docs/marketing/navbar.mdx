## Usage

```tsx

```

## API Reference

`controls` sits between the nav and the CTAs and is meant for icon buttons —
`ModeSwitchMinimal`, `ThemeSwitchMinimal` and the like. Anything with a label belongs in
`navLinks` or `cta` instead.
